# Estratégia de testes

## Prioridade

1. Testes do módulo alterado.
2. Testes do app afetado.
3. Testes de integração quando envolver core + produto.
4. Suíte completa quando a alteração for transversal.

## Ledger/Wallet

Deve ter cobertura forte para:

- crédito;
- débito;
- consumo;
- ajuste;
- transferência;
- expiração;
- saldo derivado;
- concorrência;
- transações de banco.

## HL Drive

Deve testar:

- vínculo aluno × instrutor;
- convites;
- agenda;
- consumo de horas;
- permissões derivadas de vínculo.
