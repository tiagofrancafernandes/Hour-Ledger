# Constituição

Princípios imutáveis:

- Domínio antes da arquitetura.
- Simplicidade antes de sofisticação.
- O Core nasce da reutilização comprovada.
- Nunca abstrair para consumidores hipotéticos.
- Toda mudança deve reduzir complexidade ou aumentar clareza.
- User representa identidade.
- Ledger é fonte da verdade.
- Saldo é derivado das movimentações.
- Produtos dependem do Core. O Core nunca depende dos produtos.
- Toda decisão arquitetural deve preservar boundaries.
