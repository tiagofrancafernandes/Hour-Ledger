# Framework de Decisão

Antes de qualquer mudança pergunte:

1. Estou corrigindo um bug?
2. Estou simplificando?
3. Estou melhorando o domínio?
4. Existe segundo consumidor real?
5. Estou reduzindo complexidade?

Se a resposta para abstrações preventivas for baseada em futuro hipotético, NÃO implemente.
