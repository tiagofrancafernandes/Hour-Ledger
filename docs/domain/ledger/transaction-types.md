# Tipos de transação

## Tipos previstos

### purchase

Crédito originado por compra.

### transfer

Movimentação entre wallets.

### bonus

Crédito concedido como benefício.

### refund

Estorno ou devolução.

### expiration

Expiração de crédito.

### adjustment

Ajuste administrativo.

### consumption

Consumo operacional.

## Regra

Todo tipo de transação deve preservar rastreabilidade.

Nenhuma transação deve apagar histórico anterior.
