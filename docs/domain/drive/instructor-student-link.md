# Vínculo aluno × instrutor

## Definição

O vínculo aluno × instrutor representa autorização explícita entre aluno e instrutor.

## Criação

O vínculo nasce a partir de convite e aceite.

## Fluxo

1. Instrutor cadastra ou convida aluno.
2. Sistema envia convite por e-mail.
3. Aluno faz login ou cria conta.
4. Aluno visualiza convite.
5. Aluno aceita ou rejeita.
6. Ao aceitar, vínculo é criado.

## Permissões

Permissões derivam do vínculo.

Se o vínculo existir:

- aluno pode ver agenda do instrutor;
- aluno pode fazer agendamentos;
- aluno pode acessar recursos liberados;
- instrutor pode acessar dados permitidos do aluno.

Se o vínculo for removido:

- permissões são revogadas;
- histórico permanece;
- dados sensíveis deixam de ser acessíveis.

## Histórico

Mesmo após desvínculo, registros históricos permanecem para:

- pagamentos;
- aulas;
- movimentações;
- relatórios;
- auditoria.

## Privacidade

Dados pessoais sensíveis só ficam acessíveis enquanto houver vínculo ativo.
