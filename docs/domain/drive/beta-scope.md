# Escopo beta do HL Drive

## Incluído

- controle de horas;
- ledger/wallet;
- alunos;
- instrutores;
- pacotes sem desconto;
- métodos de pagamento offline;
- PIX offline;
- dados bancários;
- instruções adicionais;
- recuperação de conta;
- timezone automático;
- português-BR fixo;
- vínculo aluno × instrutor;
- convites.

## Oculto ou desativado

- invoices;
- descontos;
- marketplace;
- multi produto público;
- automações avançadas;
- transferência de saldo;
- crédito expirável;
- promoções.

## Observação

Alguns recursos podem existir tecnicamente, mas ficar ocultos ou desativados no beta.
