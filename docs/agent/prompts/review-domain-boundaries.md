# Prompt — Revisar boundaries de domínio

Revise a alteração proposta considerando as regras do Hour Ledger:

- Core não pode conhecer HL Drive.
- Ledger deve permanecer genérico.
- Wallet é recurso core.
- Regras de aula pertencem ao HL Drive.
- Multi tenancy deve separar identidade global de dados tenantizados.
- Saldo deve ser derivado de ledger.
- Correções devem ser compensatórias.

Responda com:

1. riscos de acoplamento;
2. violações de boundary;
3. sugestões de ajuste;
4. testes necessários.
